## 🎯 Decoder-Only 模型如何训练翻译任务

### 核心思想
将翻译任务转换为**条件文本生成**任务：
```
输入序列：[BOS] Translate Portuguese to English:\n[源文本]\nEnglish: [目标文本] [EOS]
Labels:   [-100 ............................ -100 ........ -100 .] [目标token...] [EOS]
```

### 关键技术
1. **Prompt Engineering**：使用明确的指令提示模型任务
2. **Labels Masking**：
   - Prompt 部分（包括源文本）：mask 为 -100（不计算损失）
   - 目标文本部分：保留真实 token（计算损失）
3. **因果 LM 训练**：模型学会在看到 prompt 后生成目标文本

### 优势
- 统一架构：同一个 decoder-only 模型可以处理多种任务
- 灵活性：通过改变 prompt 可以轻松适配不同任务
- 现代 LLM 的标准做法（GPT、LLaMA、Kimi 等）

## 🔍 关键代码片段

### 翻译序列构建
```python
# 构建 prompt
prompt = f"Translate Portuguese to English:\n{pt_text}\nEnglish: "
prompt_ids = tokenizer.encode(prompt, add_special_tokens=False)
en_ids = tokenizer.encode(en_text, add_special_tokens=False)

# 组合序列
input_ids = [bos_id] + prompt_ids + en_ids + [eos_id]

# 构建 labels（只对英文部分计算损失）
prompt_len = len([bos_id] + prompt_ids)
labels = [-100] * prompt_len + en_ids + [eos_id]
```

### 训练循环适配
```python
# 自动检测 labels
if "labels" in batch:
    labels = batch["labels"].to(device)  # 翻译模式
else:
    labels = input_ids.clone()  # 对话模式
    labels = torch.cat([labels[:, 1:], torch.full(..., -100)], dim=1)
```
