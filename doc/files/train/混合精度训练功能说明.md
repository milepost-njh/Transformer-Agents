# 混合精度训练功能说明

## 概述

本次更新为 `train_tmp.py` 添加了混合精度训练支持，可以显著减少显存使用并提升训练速度。

## 主要特性

### 1. 自动混合精度 (AMP) 支持
- 使用 `torch.cuda.amp.autocast()` 进行前向传播
- 使用 `GradScaler` 进行梯度缩放和反向传播
- 自动处理 FP16/FP32 精度转换

### 2. 智能梯度管理
- 自动检测和跳过 inf/nan 梯度
- 改进的梯度裁剪策略
- 动态缩放因子调整

### 3. 完整的检查点支持
- 保存和加载 GradScaler 状态
- 支持训练中断后恢复混合精度训练

### 4. 详细的监控和日志
- TensorBoard 集成，记录缩放因子变化
- 详细的混合精度训练状态日志
- GPU 内存使用监控

## 配置选项

### 启用/禁用混合精度训练
```python
# 在 train_tmp.py 主函数中
use_mixed_precision = True  # 启用混合精度训练
```

### 自动回退机制
- 如果 CUDA 不可用，自动回退到标准精度训练
- 如果检测到不稳定的梯度，自动跳过当前批次

## 预期收益

### 性能提升
- **显存使用**: 减少约 50%
- **训练速度**: 提升约 1.5-2x
- **批处理大小**: 可以增加约 2x

### 稳定性保证
- 自动梯度缩放防止下溢
- 智能梯度裁剪防止上溢
- 完整的错误处理和恢复机制

## 监控指标

### TensorBoard 日志
- `Train/GradScaler_Scale`: 梯度缩放因子变化
- `Train/Avg_Gradient_Norm`: 平均梯度范数
- `Train/Max_Gradient_Norm`: 最大梯度范数

### 控制台日志
- 混合精度训练状态信息
- GradScaler 配置参数
- 内存使用情况

## 注意事项

### 1. 硬件要求
- 需要支持 Tensor Core 的 GPU (V100, A100, RTX 20/30/40 系列)
- CUDA 版本 >= 10.0

### 2. 模型兼容性
- 与现有的 MoE 和 MLA 功能完全兼容
- 支持多卡训练 (DataParallel)

### 3. 数值稳定性
- 自动处理梯度下溢/上溢
- 保持与标准精度训练相同的收敛性

## 故障排除

### 常见问题
1. **显存不足**: 尝试减小 batch_size 或启用混合精度
2. **训练不稳定**: 检查学习率设置，考虑降低学习率
3. **收敛速度慢**: 确保使用合适的学习率调度器

### 调试信息
- 查看 TensorBoard 中的 GradScaler_Scale 曲线
- 监控梯度范数变化
- 检查控制台日志中的混合精度状态信息

## 技术细节

### 实现原理
1. **前向传播**: 使用 `autocast()` 自动选择 FP16/FP32
2. **损失缩放**: 使用 `GradScaler` 放大损失值
3. **反向传播**: 自动缩放梯度，防止下溢
4. **参数更新**: 在 FP32 精度下更新参数

### 关键组件
- `torch.cuda.amp.autocast()`: 自动混合精度上下文
- `GradScaler`: 梯度缩放器
- `scaler.scale()`: 损失缩放
- `scaler.step()`: 优化器步骤
- `scaler.update()`: 更新缩放因子

这个实现确保了混合精度训练的安全性和有效性，同时保持了与现有代码的完全兼容性。
