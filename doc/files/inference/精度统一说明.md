# KV-cache 精度说明

## 项目使用精度

所有 KV-cache 相关计算统一使用 **bf16 (bfloat16)** 精度：
- **每参数占用**: 2 bytes
- **优势**: 相比 float32 节省 50% 显存，数值稳定性好

## 精度对比

| 精度 | 字节 | 数值范围 | 适用场景 |
|------|------|---------|---------|
| float32 | 4 | ±3.4e38 | 训练（高精度） |
| float16 | 2 | ±6.5e4 | 推理（易溢出） |
| **bf16** | **2** | **±3.4e38** | **训练+推理（推荐）** |

## 实验验证 (64 tokens)

**理论计算 (bf16)**:
```
Standard: 2 × 8头 × 64 × 8层 × 64tokens × 2bytes = 1.00 MB
MLA:      (128+32+512) × 8层 × 64tokens × 2bytes = 0.66 MB
压缩比:   34.0% ✅
```

**实验结果**:
```
MLA:      0.66 MB KV-cache | 55.42ms/step
Standard: 1.00 MB KV-cache | 38.67ms/step
节省:     34.0% 显存 | 速度慢 43.3%
```

## 代码实现

KV-cache 计算（bf16）:
```python
# 标准注意力
kv_size_mb = (2 * num_heads * head_dim * seq_len * num_layers * 2) / (1024 * 1024)

# MLA
kv_size_mb = ((kv_lora_rank + qk_rope_head_dim + num_heads*v_head_dim) * seq_len * num_layers * 2) / (1024 * 1024)
```
