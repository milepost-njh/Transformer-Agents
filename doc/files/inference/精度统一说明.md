## 精度统一

### 统一标准

所有 KV-cache 相关的计算和实验统一使用 **bf16 (bfloat16)** 精度：
- **每个参数占用**: 2 bytes
- **原因**: 与文档中的理论计算保持一致
- **优势**: 节省显存，同时保持足够的数值精度

### 精度对比

| 精度类型 | 字节/参数 | 数值范围 | 精度 | 使用场景 |
|---------|----------|---------|------|---------|
| float32 | 4 bytes | ±3.4e38 | 7位有效数字 | 训练（高精度） |
| float16 | 2 bytes | ±6.5e4 | 3位有效数字 | 推理（易溢出） |
| bf16 | 2 bytes | ±3.4e38 | 3位有效数字 | 训练+推理（推荐） |

### 为什么选择 bf16？

1. **显存效率**: 相比 float32 节省 50% 显存
2. **数值稳定**: 相比 float16 有更大的数值范围，不易溢出
3. **硬件支持**: 现代 GPU (A100, H100, L20) 原生支持
4. **兼容性好**: 可以直接与 float32 混合使用

## 代码示例

### 正确的 bf16 计算 ✅

```python
# KV-cache 大小计算 (bf16)
def calculate_kv_cache_size(num_layers, num_heads, head_dim, seq_len):
    """计算标准注意力的 KV-cache 大小"""
    params_per_token = 2 * num_heads * head_dim  # K + V
    total_params = params_per_token * num_layers * seq_len
    size_mb = total_params * 2 / (1024 * 1024)  # bf16: 2 bytes
    return size_mb

# 示例: 8层, 8头, head_dim=64, 64 tokens
size = calculate_kv_cache_size(8, 8, 64, 64)
print(f"KV-cache 显存: {size:.2f} MB")  # 输出: 1.00 MB
```
