# 1. KV Cache 存储量计算

## 1.1 模型配置对比

### 1.1.1 你的模型配置
- **模型层数**: 8层
- **注意力头数**: 8个Head
- **每个Head的向量维度**: 64
- **总隐藏维度**: 512

### 1.1.2 Qwen-72B 配置
- **模型层数**: 80层
- **注意力头数**: 64个Head
- **每个Head的向量维度**: 128
- **总隐藏维度**: 8192

## 1.2 单个token的KV Cache计算

### 1.2.1 不同注意力机制的KV Cache计算公式
- **MHA (Multi-Head Attention):** `KV Cache = 层数 × 注意力头数 × 头维度 × 2(K和V)`
- **MQA (Multi-Query Attention):** `KV Cache = 层数 × 头维度 × 2(K和V)`
- **MLA (Multi-head Latent Attention):** `KV Cache = 层数 × (4 × 头维度 + 头维度 / 2)` (每个Transformer层缓存 c_t^KV 和 k_t^R)

### 1.2.2 具体数值

**你的模型 (MHA):**
```
8层 × 8个Head × 64维度 × 2(K和V) = 8,192个参数
```

**你的模型 (MQA):**
```
8层 × 64维度 × 2(K和V) = 1,024个参数
```

**你的模型 (MLA):**
```
8层 × (4 × 64维度 + 64维度 / 2) = 8层 × (256 + 32)维度 = 8层 × 288维度 = 2,304个参数
```

**Qwen-72B (MHA):**
```
80层 × 64个Head × 128维度 × 2(K和V) = 1,310,720个参数
```

### 1.2.3 内存占用

假设使用bf16精度（2字节/参数）：

**你的模型 (MHA):**
```
8,192个参数 × 2字节 = 16,384字节 = 16KB
```

**你的模型 (MQA):**
```
1,024个参数 × 2字节 = 2,048字节 = 2KB
```

**你的模型 (MLA):**
```
2,304个参数 × 2字节 = 4,608字节 = 4.5KB
```

**Qwen-72B (MHA):**
```
1,310,720个参数 × 2字节 = 2,621,440字节 = 2.62MB
```

mem_kv = 1token_mem_kv × B × S
